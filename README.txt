Team Task Manager

Description:
A Django-based web application for managing projects and tasks with role-based access control.

Features:
- User Authentication (Signup/Login)
- Role-Based Access (Admin/Member)
- Project Management
- Task Assignment
- Task Status Tracking
- Dashboard Analytics
- REST APIs
- Railway Deployment

Tech Stack:
- Django
- Django REST Framework
- SQLite
- Bootstrap
- Railway

Roles:

Admin:
- Create/Delete Projects
- Create/Delete Tasks
- Create/Delete Users

Member:
- View Tasks
- Track Task Progress

REST APIs:
- /api/tasks/
